## MODIFIED Requirements

### Requirement: 运行配置按环境隔离
系统 SHALL 允许开发、测试和生产使用独立配置，生产秘密 MUST 从运行环境或秘密管理设施注入，不得存在于仓库或构建产物中。生产环境启动时 SHALL 校验认证签名密钥和手机号 pepper 已显式注入、长度不低于 32 字符且不等于仓库中的开发示例值，并 MUST 拒绝启用本地模拟登录模式；校验失败时进程 MUST 在监听 HTTP 前退出且不输出配置值。

#### Scenario: 运行自动化测试
- **WHEN** 测试套件启动服务端
- **THEN** 服务端只使用隔离测试配置和测试数据库，不访问生产资源

#### Scenario: 生产缺少显式秘密
- **WHEN** 以生产环境启动但未注入认证签名密钥或手机号 pepper，或注入的值仍是仓库中的开发示例值
- **THEN** 进程以非零结果退出，不使用默认秘密签发任何令牌，且日志只输出稳定错误类别

#### Scenario: 生产启用模拟登录
- **WHEN** 以生产环境启动且手机号登录模式为 `mock`
- **THEN** 进程以非零结果退出，不暴露固定验证码登录入口
