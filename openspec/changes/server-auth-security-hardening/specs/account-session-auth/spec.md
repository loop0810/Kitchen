## MODIFIED Requirements

### Requirement: 用户可以管理和删除账号
系统 SHALL 允许用户退出当前设备、退出所有设备以及在 App 内发起账号删除；账号删除 SHALL 撤销全部会话并按权威删除规则处理服务端账号数据，但 MUST 将是否删除本机菜谱作为独立的明确选择。要求近期重新认证的敏感操作 SHALL 以设备会话的建立时间判定，MUST NOT 使用会随刷新前移的访问凭证签发时间；会话校验 SHALL 同时拒绝已撤销和已过期的设备会话。

#### Scenario: 仅删除账号
- **WHEN** 用户确认删除账号但未选择清除本机数据
- **THEN** 服务端账号进入删除流程，全部服务端会话失效，本机菜谱保持可用

#### Scenario: 长期会话执行敏感操作
- **WHEN** 客户端持有由长期会话刷新得到的有效访问凭证，并请求解绑身份等要求近期重新认证的操作
- **THEN** 服务端因会话建立时间超出近期重新认证窗口而拒绝该操作

#### Scenario: 会话已过期
- **WHEN** 客户端使用尚未撤销但已超过有效期的设备会话调用账号接口
- **THEN** 服务端返回稳定的会话失效错误
