# 服务端迭代学习记录

## 命名

文件使用三位递增序号和主题：`NNN-kebab-case-topic.md`，例如 `001-vapor-bootstrap.md`。序号表示学习顺序，不替代 OpenSpec change 名称。

## 完成条件

服务端 change 在全部实现和验证任务完成后、归档前，必须：

1. 根据 [`iterations/TEMPLATE.md`](iterations/TEMPLATE.md) 新增或更新学习记录；或
2. 在 change 的 `tasks.md` 完成说明中写明“学习记录豁免”，并说明本次为何没有新的概念、权衡、失败教训或可复用流程。

学习记录链接最终代码、测试、migration、contract、decision 和 OpenSpec，不复制其完整内容。记录应描述实际结果，而不是实施前的猜测。
