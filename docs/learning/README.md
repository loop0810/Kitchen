# 学习记录

## 权威范围

本分区保存完成实现后的学习复盘，帮助按迭代理解最终架构、关键概念、验证方式、问题修正和代码入口。它面向项目维护者和学习者。

## 不负责

- 规定产品行为、共享接口或工程约束。
- 复制 OpenSpec proposal、tasks、完整需求或大段生产代码。

服务端记录从 [`server/README.md`](server/README.md) 进入。权威要求必须链接到 product、contracts、decisions 或 OpenSpec，而不是在学习记录中重新定义。
