# 媒体资源服务需求

## 1. 定位

媒体资源服务统一管理用户图片、导入截图、菜谱封面、烹饪照片、模板资源和
缩略图。它提供文件生命周期和引用，不负责理解图片内容。

## 2. 服务对象

- 导入处理服务。
- 菜谱编辑器和详情。
- 手账模板服务。
- 烹饪记录。
- 备份与同步服务。

## 3. 资源类型

- 原始导入图片。
- OCR 预处理图片。
- 菜谱成品图。
- 步骤图。
- 烹饪记录照片。
- 手账背景、胶带、贴纸和字体。
- 菜谱及模板缩略图。
- 菜谱集裁切封面。

## 4. 职责

- 将临时输入复制到应用受控目录。
- 生成稳定资源 ID 和元数据。
- 按用途生成缩略图或预览图。
- 记录宽高、格式、大小、校验值和创建时间。
- 按显示尺寸解码，降低内存占用。
- 维护资源引用计数或引用查询。
- 清理无引用和过期临时资源。
- 为导出和备份提供资源清单。

## 5. 非职责

- 不执行 OCR。
- 不决定 AI 是否上传图片。
- 不负责模板布局。
- 不直接操作业务数据库表之外的领域规则。
- 不将本地绝对路径作为可同步的业务 ID。

## 6. 存储规则

- 数据库存储资源 ID 和相对定位，不保存开发机路径。
- 临时分享文件先复制成功，再确认接收完成。
- 原图与派生缩略图分开标识。
- 用户删除原图时明确派生资源处理规则。
- 模板内置资源与用户资源使用不同命名空间。
- 文件名不依赖用户原始文件名。

## 7. 图片处理

P0：

- 读取图片方向信息。
- 生成列表缩略图。
- 控制最大解码尺寸。
- 支持 JPEG、PNG 和平台常见格式。
- 菜谱集封面固定按 3:4 裁切，并限制到适合高密度书封的 JPEG 尺寸与质量。

P1：

- HEIF/HEIC 兼容。
- 裁剪、旋转和压缩。
- OCR 增强版本。
- 内容校验与重复检测。

## 8. 隐私

- 用户图片默认只保存在本地。
- 上传云端前由调用方取得明确授权。
- 服务向上传方提供可审计的临时副本，不默认永久上传。
- 日志不记录图片内容或完整本地路径。
- 分享扩展接收的数据要在完成复制后清理临时引用。

## 9. 失败与降级

- 缩略图生成失败时仍保留原图。
- 模板装饰资源缺失时交由模板服务使用默认资源。
- 磁盘空间不足时给出可理解提示并保留任务状态。
- 图片损坏时允许重新选择或忽略。
- 清理失败下次重试，不阻塞核心读取。

## 10. 验收

- 应用重启后资源 ID 仍可解析。
- 删除菜谱不会误删仍被其他记录引用的图片。
- 列表不直接解码超大原图。
- 原始导入图片与用户裁剪结果可区分。
- 导出可以获得完整且去重的资源列表。
